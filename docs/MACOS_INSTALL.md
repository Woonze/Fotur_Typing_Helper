# Установка Fotur Typing Helper 1.3.0 на macOS

Выберите пакет:

- Mac с процессором Apple M1/M2/M3/M4/M5: `FoturTypingHelper-1.3.0-macos-arm64.dmg`.
- Mac с процессором Intel: `FoturTypingHelper-1.3.0-macos-x64.dmg`.

## Установка

1. Откройте DMG.
2. Перетащите `Fotur Typing Helper.app` в `Applications`.
3. Запускайте именно копию из `Applications`, а не приложение из DMG или Downloads.

## Разрешения

Для полной работы нужны:

- «Микрофон» — запись диктовки.
- «Мониторинг ввода» — глобальные хоткеи и анализ набора.
- «Универсальный доступ» — удаление и вставка исправленного текста.

Fotur 1.3.0 проверяет эти права при каждом запуске и не закрывается, если разрешения ещё не выданы. В разделе «Настройки → Разрешения macOS» есть кнопки для открытия нужных Privacy-разделов.

Если macOS сама попросит закрыть и открыть приложение заново после изменения разрешения, выполните именно это системное требование.

## Gatekeeper

Сборки имеют ad-hoc подпись. Без Apple Developer ID приложение пока нельзя нотарифицировать, поэтому macOS может потребовать открыть приложение через «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть».
