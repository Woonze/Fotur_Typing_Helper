# Каталог функций Fotur Typing Helper 1.3.0

Документ описывает фактическое поведение версии 1.3.0. Незавершённые и требующие ручной проверки пункты находятся в [BACKLOG.md](BACKLOG.md).

## 1. Автоматическое исправление раскладки

Windows и macOS собирают текущее слово и контекст фразы, сравнивают исходный фрагмент с EN↔RU-конверсией и при достаточной уверенности заменяют ошибочный текст. Исправление сохраняет регистр, защищает бренд `Fotur`, известные имена, корректные английские слова и технические фразы.

В 1.3.0 восстановлен нормальный русский словарь scorer’а после повреждения кодировки и расширена защита команд: `docker compose`, `docker compose up -d`, `git push origin main`, `npm install`, `json config`.

## 2. Диктовка

Диктовка работает локально через Whisper. Поддерживаются русский, английский, автоматическое определение языка и отдельный режим локального перевода речи на английский. Настройки включают модель, микрофон, VAD, noise gate, prompt личного словаря, голосовую пунктуацию и фильтр слов-паразитов.

Во время записи показывается фирменная подсветка краёв экрана. На macOS overlay прозрачен для кликов.

## 3. Горячие клавиши

Горячие клавиши диктовки и отмены можно переназначить. Валидация не допускает пустую клавишу, две основные клавиши в одном сочетании, совпадение диктовки и отмены, а также системные reserved-комбинации.

## 4. Автообновление

При запуске приложение проверяет latest stable GitHub Release, выбирает asset текущей платформы и сверяет SHA-256. В 1.3.0 исправлены повреждённые сообщения updater’а, добавлена обработка отсутствующего release/сетевой ошибки без падения и добавлен выбор Linux x64 asset.

Windows запускает installer. macOS обновляет установленный `.app` через helper-скрипт. Linux 1.3.0 скачивает и проверяет архив, но установку поверх текущей папки пользователь выполняет вручную.

## 5. Платформы

- Windows x64: основной проверенный режим, low-level keyboard hook, SendInput, NAudio, Whisper CPU runtime, installer и portable.
- macOS Apple Silicon/Intel: CGEvent tap/post, OpenAL capture, Whisper CoreML/CPU, DMG/ZIP, проверка Microphone/Input Monitoring/Accessibility при запуске.
- Linux x64: experimental. UI и диктовка упакованы; запись через `arecord`, вставка через `xdotool` на X11. Глобальные хоткеи и автокоррекция пока отключены.

## 6. Приватность

Пользовательский текст и аудио не логируются и не отправляются в облако. Локальный журнал содержит только технические ошибки. Статистика хранит числа исправлений, слов и сэкономленных нажатий.
